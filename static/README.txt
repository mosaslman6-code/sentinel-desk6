SentinelDesk 3.3 - نظام إدارة حوادث الأمن السيبراني
======================================================

التشغيل
  Windows : فك الضغط ثم انقر مرتين على start.bat (يفتح المتصفح على http://127.0.0.1:8000)
  Linux/Mac: python3 server.py
  المطلوب فقط Python 3.8 أو أحدث، ولا حاجة لتثبيت أي مكتبة. أبقِ النافذة السوداء مفتوحة أثناء الاستخدام.

الحسابات الافتراضية (غيّرها قبل أي عرض)
  admin / Admin@123       مدير
  analyst / Analyst@123   محلل
  sara / Analyst@123      محللة
  viewer / Viewer@123     مشاهد (قراءة فقط)

طريقة العمل (موجودة أيضاً في صفحة "دليل سريع" داخل النظام)
  1. الإبلاغ: "حادث جديد" (اختر قالباً جاهزاً لتعبئة النموذج)
  2. الفرز: حدّد الخطورة وعيّن مسؤولاً
  3. التوثيق: الإجراءات، قائمة التحقق، المؤشرات، الأدلة
  4. الاحتواء ثم الحل
  5. الإغلاق مع السبب الجذري والدروس المستفادة، ثم "إنشاء تقرير" للطباعة أو PDF

أهم الصفحات
  لوحة المعلومات، الحوادث (جدول أو لوحة)، المؤشرات، الأصول، التقارير،
  وللمدير: المستخدمون، سجل التدقيق، صحة النظام، قاعدة البيانات، الإعدادات.

مختبر الهجمات (اختياري): من لوحة المعلومات اضغط "تشغيل مختبر الهجمات" - التفاصيل في attack_lab/README_AR.md

الاختبارات: python3 -m unittest discover -s tests
